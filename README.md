# Computer Networking Project with Cisco Packet Tracer

This is a project I built while learning computer networking using Cisco Packet Tracer.

You can learn more about Cisco Packet Tracer on the official website:
https://www.netacad.com/cisco-packet-tracer

With Cisco Packet Tracer, I learned how to design network topologies and make sure all devices run properly.

- Static Routing
